1. Start a coding or general-use agent

Pi — recommended starting point

pi

Starts Qwen3.8-Flash-Next 4-bit EXL3 on Kyojin, then opens Pi in your current project directory. Its file and terminal tools are configured.

Hermes — alternative agent

hermes

Starts the same Qwen EXL3 / Kyojin setup, with its own saved sessions and compression configuration. Use it for coding or general conversation.

Open your project directory first, then run either command. The large model loads on the first launch. These defaults have 262,144 total context tokens; input, tool messages, reasoning and replies share that space. Earlier testing passed 10/10 small coding tasks and 200K recall for this model.

Copying output in Konsole: press Ctrl+X in Pi to copy the last assistant response. For terminal-selected text, use Konsole’s Ctrl+Shift+C. The Wayland clipboard utilities wl-copy / wl-paste are installed in your user command path.

Exiting: in Pi, use /quit or its alias /exit. Existing Pi sessions can load the alias with /reload. Exit other harnesses normally, or use Ctrl-C as appropriate. The engine stays loaded for reuse. To release GPU memory or switch model families:

localai stop

2. Create images and videos in ComfyUI

run-comfyui

Starts ComfyUI and opens http://127.0.0.1:8188. Keep its terminal open; Ctrl-C stops the server. From another terminal you can stop it with:

stop-comfyui

In the left sidebar choose Workflows → Ready-to-use. Open a preset, edit the prompt, then click Run. The five native UI workflows have model selections, encoders, VAEs, sampler settings and outputs wired already.
