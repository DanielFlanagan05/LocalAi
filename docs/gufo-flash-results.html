Gufo Flash-Next: measured, local and retained

Fresh prefill clears 1,200 tokens/s through 200K input. The requested 1,500 tokens/s has not been demonstrated. The previous EXL3 model remains installed. No retained models were removed for this comparison.

Launch from any project

localai stop       # finish any existing work before switching
pi-gufo           # Pi + Flash-Next Q4 / Gufo
# or: hermes-gufo
# Stop the engine when finished:
localai stop

Native context: 262,144 total tokens, shared by input, tools, reasoning and output; one execution session. Ordinary pi and hermes retain their Kyojin EXL3 defaults. pi-local / hermes-local retain the smaller Gufo 27B setup. Desktop entries: Pi Gufo Flash and Hermes Gufo Flash.

Three repetitions per 2K/8K/32K target, reported as medians; one run each at 131K/200K. Tokenizer-calibrated synthetic recall, greedy, thinking off, cache lookup explicitly disabled. All rows passed exact recall; actual fresh input exceeded each target and cached input was zero. These are engine prefill rates, not sustained generation or coding-quality scores.

Official Gufo 0.20.0, revision 0c03748a, ROCm 7.2.3, pinned container and the guide’s exact Unsloth revision. AC power, firmware Performance, GPU clock policy auto. MTP’s first qualification retained at least 19.4 GiB unified-memory headroom; its maximum sampled runtime-process swap was about 59 MiB. GPU edge reached 95°C in the AR run; sustained MTP prefill was commonly around 90–94°C with roughly 70 W PPT. These observations suggest a device power/thermal contribution, not a proven root cause.

The ready-to-use configuration passed: 12 GiB RAM / 16 GiB disk cache, with an 8 GiB free-memory guard. Fresh 8K median: 1,450 tok/s; fresh 200K: 1,290 tok/s. A subsequent continuation reused 200,125 tokens and answered correctly in 0.39 seconds (first output 0.21 seconds). Minimum free memory: 12.7 GiB; sampled runtime-process swap: zero. This establishes live cache reuse; restart recovery was not tested. The table above used the initial 1 GiB cache control. The high GPU policy comparison is complete: 1,392 / 1,383 / 1,353 tok/s medians at 2K / 8K / 32K, and 1,187 tok/s at fresh 200K. Every measured row stayed on high and passed fresh-token/recall checks. A 200K continuation reused 200,125 tokens in 0.392s, with 13.6 GiB minimum free memory and zero sampled runtime-process swap. High did not demonstrate a performance benefit; retain auto. The helper restored GPU policy to auto; no inference runtime remains active.

Halogen is not installed: the high-policy 200K result fell below 1,200, but the better Gufo auto configuration reached 1,290. The user chose to continue with Gufo for now. Halogen is recorded as a deferred comparison in the retained plan; it is not being installed or tested now. Its default HGN pack would add about 118 GB while preserving existing packs. NPU: the production package uses HIP/GPU; its published headline rates do not require an NPU. Flash-Next NPU offload remains an unmerged experiment reporting a modest gain with additional clock/driver requirements. It was not installed.
