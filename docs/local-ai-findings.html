What I would use

Everyday coding & multiple sessions

Pi + Qwen3.8-27B Q4 on Gufo. Best practical default from this work: 10/10 coding tasks, working tools, and an earlier two-session 200K recall pass. Both sessions are configured for 262,144 tokens; allow room for replies. The latest cache budget still lacks a full concurrent long-context repeat.

Large-model coding & long reading

Qwen3.8-Flash-Next EXL3 on Kyojin. My preferred large candidate: 10/10 coding tasks, 4/4 document pages, and the fastest observed large-model prefill here. Use coding-quality at 262K; reserve the draft-free 512K profile for experimental long reading.

ClearCase vision → text

8B for parallel trials; Qwen EXL3 for a stronger serial option. The bundled Qwen3-VL-8B is economical but invented some unsupported fields. Qwen EXL3 and the larger GLM both passed the four synthetic pages; Qwen was faster. Keep validation and human review for real documents.

ComfyUI image & video work

Z-Image Turbo for quick drafts; Qwen-Image / FLUX.2 for quality exploration; H3 / LTX for video with audio. Chroma and Wan AIO are the installed permissive-content candidates. Execution works, but testing did not establish a best-quality or “most uncensored” winner.

Memory, storage & where testing ends

  • Memory: BIOS reservation is 0.5 GiB, approximately 125 GiB is visible to Linux, and dynamic GTT is capped at 112 GiB. This is shared RAM, not an additional 112 GiB of dedicated VRAM. Keep OS/desktop and KV/cache headroom.
  • Gufo cache: 26 GiB RAM snapshots / 40 GiB disk / 16 GiB staging. After a real restart, the 200K check restored 200,107 tokens and replied in 11.31 s; 32K restored in 2.62 s. The older 32 GiB RAM budget exhausted the reserve before 225K; the revised single-session 225K ladder passed.
  • Large-model limits: 500K draft-free Qwen showed about 0.84 GiB process swap; MiMo about 1.29 GiB. GLM also showed swap activity. No no-swap or overnight reliability acceptance was achieved.
  • Shared files: weights are in ~/.local/share/localai/models, readable from any repository. localai models-path prints the path. Sessions/reports use ~/.local/state/localai; caches use ~/.cache/localai. Git excludes weights, sessions and context checkpoints. Launchers, dependencies and pinned runtimes are installed outside the checkout.
Not completed: full revised-cache dual-200K/225K ladder, corrected Claude lifecycle, sustained 485K coding, 27B 512K/1M and GLM 512K experiments, Q8 concurrency, long-context parallel vision, expanded document variants, full-resolution images/reference edits/longer video, and the two-hour/eight-hour reliability run.
